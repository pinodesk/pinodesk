# Security Policy

## Supported Versions

Currently, only the latest version of Pinodesk is actively supported with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately rather than creating a public issue.

### How to Report

1. Send an email to the project maintainers
2. Include a detailed description of the vulnerability
3. Provide steps to reproduce the issue if possible
4. Include any relevant code or configuration

### What to Expect

- We will acknowledge receipt of your report within 48 hours
- We will provide a detailed response within 7 days
- We will work with you to understand and resolve the issue
- We will coordinate a release schedule for the fix

## Security Best Practices

When using Pinodesk in your projects:

- Keep dependencies up to date
- Review security advisories for dependencies
- Use the latest stable version of Pinodesk
- Enable security scanning in your CI/CD pipeline
